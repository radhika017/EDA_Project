# 📊 Exploratory Data Analysis (EDA) on Netflix Dataset

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on the Netflix Titles dataset using Python.
The objective of this project is to explore the dataset, identify patterns and trends, detect missing values and anomalies, and generate meaningful insights through statistical analysis and visualizations.

---

## 🎯 Objectives

* Understand the structure of the dataset
* Perform data cleaning and preprocessing
* Identify missing values and duplicates
* Analyze trends and patterns
* Visualize data using charts and graphs
* Generate insights from the dataset

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* VS Code

---

## 📂 Dataset

The dataset used in this project is the **Netflix Titles Dataset** containing information about movies and TV shows available on Netflix.

Dataset features include:

* Title
* Director
* Cast
* Country
* Release Year
* Rating
* Duration
* Genre

---

## 📈 Tasks Performed

### ✔ Data Exploration

* Checked dataset structure
* Analyzed rows, columns, and data types

### ✔ Data Cleaning

* Detected missing values
* Removed duplicate records

### ✔ Statistical Analysis

* Generated descriptive statistics
* Identified trends and distributions

### ✔ Data Visualization

Created visualizations such as:

* Heatmaps
* Histograms
* Count plots
* Boxplots

### ✔ Trend Analysis

* Compared Movies vs TV Shows
* Analyzed release year distribution
* Explored content patterns

---

## 📊 Key Insights

* Netflix contains more Movies than TV Shows.
* Several columns contain missing values such as director and cast.
* Most content was released after 2015.
* Visualization helped identify trends and data distribution patterns.
